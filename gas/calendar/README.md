# 行事曆公開讀取後端

這份 Apps Script 將公開網頁改為「直接讀取 Google 日曆」。公開入口 `doGet()` 不會讀取、清空、寫入或修改任何試算表。

## 建議做法：公開頁面直接讀取日曆

一般使用者不需要管理者登入介面。`calendar.html` 會依目前顯示的 10 天、週、月份或自訂日期範圍，直接向 `doGet()` 查詢最新日曆活動。自訂範圍預設為 2026/08/01～2028/06/30，最長可查詢 730 天。

更新既有 Apps Script 部署：

1. 在原本的 Apps Script 專案中，以 [Code.gs](./Code.gs) 取代舊程式。
2. 儲存後，選擇「部署」→「管理部署作業」。
3. 編輯現有部署，選擇「建立新版本」，再按「部署」。
4. 保持「執行身分」為擁有者，並依原本需求允許具連結者存取。
5. 用下列格式測試既有 `/exec` 網址：

   `https://script.google.com/macros/s/部署代碼/exec?start=2026-08-01&end=2026-08-10`

成功時會回傳 `{"status":"success","data":[...]}`。更新現有部署的新版本後，原本的 `/exec` 網址不需要更換。

## 安全注意事項

- 公開查詢最長限制為 730 天，可涵蓋預設的自訂日期範圍。
- 建議日曆活動只填寫可公開的標題、地點與說明。
- 程式完全不使用 `SpreadsheetApp`，日曆若有新增、修改或刪除，網頁下次查詢時會直接取得目前的日曆內容。
- 部署新版後，再發布新版 `calendar.html`，避免前端先上線而舊後端仍會寫入試算表。
